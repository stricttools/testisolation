## 0.3.0

First release under the name testisolation, with the module path github.com/stricttools/testisolation/go.

<details>
<summary>Context</summary>

The project stricttest is renamed to testisolation, on every surface at once: the repository (github.com/stricttools/testisolation), the PyPI and npm packages, the Python import name and pytest plugin, the pytest ini key prefix, the sandbox environment variable, and the Go module path, which also moves from the smm-h path to the stricttools organization. The stricttest packages already published on PyPI and npm stay where they are and receive no further releases.

</details>

### Breaking

- [go-testisolation] **stricttest is renamed to testisolation, and the Go module path is now `github.com/stricttools/testisolation/go`.** It was `github.com/smm-h/stricttest/go`. Change the require line and every import of `hygiene` and `pgcluster` to the new path. The git identity the hygiene package sets for a test is now named `testisolation`.

### Fixes

- [go-testisolation] **The tool describes itself with one sentence everywhere.** The README now carries the same line as the project's other surfaces.
