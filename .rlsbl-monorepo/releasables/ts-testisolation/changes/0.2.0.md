## 0.2.0

First release under the name testisolation: the npm package and sandbox variable are renamed from stricttest.

<details>
<summary>Context</summary>

The project stricttest is renamed to testisolation, on every surface at once: the repository (github.com/stricttools/testisolation), the PyPI and npm packages, the Python import name and pytest plugin, the pytest ini key prefix, the sandbox environment variable, and the Go module path, which also moves from the smm-h path to the stricttools organization. The stricttest packages already published on PyPI and npm stay where they are and receive no further releases.

</details>

### Breaking

- [ts-testisolation] **stricttest is renamed to testisolation.** The npm package is now `testisolation` and the repository is github.com/stricttools/testisolation. The sandbox variable read by default is now `TESTISOLATION_SANDBOX`, the git identity set for a test is named `testisolation`, and temporary directories carry the `testisolation-` prefix. Replace the `stricttest` dev dependency with `testisolation` and update the imports; the old package receives no further releases.

### Fixes

- [ts-testisolation] **The tool describes itself with one sentence everywhere.** The README and npm metadata now carry the same line as the project's other surfaces.
